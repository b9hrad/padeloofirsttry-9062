# Padeloo — a study in restraint

## Direction
Responsive web only. Follow the supplied creative brief directly; no visual template. Quiet architectural identity, disciplined editorial layout. No photography until genuine facility images are supplied. Never invent venue specifications, address, prices, availability or social accounts.

## System
IBM Plex Sans, self-hosted, regular display and body, medium navigation and wordmark. Charcoal #18181b, secondary #222126, warm white #e9e6e1, muted #a09da5, midnight purple #30243c for interaction states only. No gradients, effects, shadows or cards.
Content max 1200px, desktop gutter 64–80px, mobile 24px. Spacing 8/16/24/40/64/96/128. Hairline separators, rectangular buttons, quiet sentence-case headings. One custom court graphic with a deliberately interrupted perimeter and an offset net.

## Composition
Two-column hero, editorial Courts section, one warm-white Club section, Academy and Events disclosure rows, compact location/footer. Deliberate mobile proportions rather than a simple desktop stack.

## UX and engineering
Anchor navigation, accessible mobile menu, native booking dialog with Escape, trapped focus and focus restoration. Booking explicitly an unconnected prototype; no fake slots or reservations. Program details are pending. Frontend changes only in packages/web; no new API routes or database tables. Keep managed infrastructure and analytics. Reduced-motion support, visible focus and semantic landmarks. Test at 1440 and 390px, exercise interactions, run production build.
